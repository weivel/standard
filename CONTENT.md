## What this is

The weivel standard: the defaults weivel ships beside its core, as one C library a host may link or ignore. It reads and
validates the JSON manifest, finds plugins on disk, and defines the config, secrets, paths, log, scope and host
services.

## What this is not

It is not the core, and the core does not know it. Every default here can be replaced.
