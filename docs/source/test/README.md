The standard's tests and the fixtures they plant, registered by this folder's CMake when the standard is the top project. Most behaviours have three tests in the same shape: a test of the behaviour against the static library, the same test against the shared library (`*_shared_test`), which proves the exports and the ABI, and a memory test (`*_memory_test`) against the testing build, which fails each allocation in turn and checks that the answer is out of memory and that no block is left. `abi_test.c` holds the size convention to every public struct with a caller compiled before and after a field was appended, and the `layouts/` folder holds the program and scripts that give languages the C compiler's layouts. `schema_parity_test.c` holds the validator to the published schema, with `validate_rules.c` as the table of rules; [the validation doc](../../validation.md) states the two rules beside the schema. The `describe_*` tests hold `weivel-describe` to its grammar, its refusals and its golden output (see [the descriptions doc](../../descriptions.md)), and the `described_*` tests load a real shared library that is described by the program and bind it as a host does.
