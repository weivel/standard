The weivel standard is the default layer weivel ships beside its core: one C library that a host may link or ignore, holding everything the core deliberately does not know. The core takes a manifest, a clock and every other value through its C interface and reads no file, environment or format; the standard supplies the defaults a host would otherwise write itself. It owns seven things. The JSON reader and the JSON manifest read into the core's manifest structure, validated against the schema this repository publishes (`schema/plugin.schema.json`) and the two rules beside it that a schema cannot say. Repository identities, and plugins laid out and discovered on disk. The library declaration, the file in which a C library names the services its functions offer. The description a C library answers for a definition, with the check every binding runs on it first, and `weivel-describe`, the program that writes one from a header. The config, secrets, paths and log services, the scope that gives each plugin its own, and the host service through which a program asks its provider what to run, each an id and a C struct of function pointers that every language translates, with the value tree a definition hands data in. The format of a mirror list a host can fetch the core's binary from, and the check that a download is the file that was asked for. The conventions every one of these follows: sized structs that only grow, refusals as data, and one allocator. It implements none of the core: it depends on the core and the core knows nothing of it. Replaceable is the design, and [replacing.md](replacing.md) states what that means, what the standard takes from the core and what a replacement must still honour. The conformance kit holds the standard to its behaviour with vectors the standard does not own (see the conformance kit's `docs/vectors/`), and weivel's core, C, Java and TypeScript implementations keep their own docs. How to build the library, run its tests and run the description program is answered in [the source mirror's root doc](source/README.md).
